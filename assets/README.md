# Elshamii Assets

Place application resources here:
- `icons/`: interface icons (PNG/ICO/SVG source files)
- `images/`: backgrounds and illustrations
- `logos/`: Elshamii and partner logos
- `fonts/`: licensed font files
- `flags/`: language flags
- `sounds/`: notification sounds

Use relative paths through `desktop/resources.py`; do not hardcode machine-specific paths.
